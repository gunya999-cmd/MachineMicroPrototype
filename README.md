# MachineMicroPrototype

Микропрототип физической головоломки в духе The Incredible Machine.

Игрок перетаскивает предметы в режиме редактирования, запускает симуляцию
и наблюдает, как цепная реакция приводит шар к цели.

## Статус

- Версия: v0.1
- Цель: личный прототип

## Движок

- Unity 2022 LTS или новее
- Шаблон: 2D Core

## Платформы

- PC
- WebGL
- Android
- iOS

## Возможности v0.1

- Перетаскивание объектов мышью или пальцем
- Режимы Edit / Run
- Кнопка Start запускает физику
- Кнопка Reset возвращает объекты в состояние до запуска
- Цель уровня: шар должен попасть в Target
- Экран победы

## Как открыть проект

1. Установить Unity 2022 LTS или новее.

2. Открыть Unity Hub.

3. Нажать Add.

4. Выбрать папку проекта MachineMicroPrototype.

5. Открыть сцену:

   Assets/Scenes/MicroPrototype.unity

6. Нажать Play.

## Управление

- В режиме Edit: перетаскивать шар, ящик и рампу мышью или пальцем.
- Start: запустить физику.
- Reset: вернуть объекты назад.
